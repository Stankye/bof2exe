# Command reference

Generated by `bof2exe docs` from the CLI model.

## bof2exe

```text
Turn Windows BOFs into standalone command-line tools

Usage: bof2exe <COMMAND>

Commands:
  init          Create an editable command-line schema for a BOF, optionally using CNA metadata
  build         Build a standalone CLI from a tool schema or directly from a BOF/CNA signature
  inspect       Describe sections, symbols, imports, and compatibility without executing code
  check         Validate an object; exit unsuccessfully when static compatibility checks fail
  run           Run an object in a separate worker process (Windows x64)
  bundle        Create an executable containing the object and default arguments (Windows x64)
  pack          Encode typed arguments for use with the library or another Beacon runtime
  cna           Analyze CNA command registrations, packing signatures, and parameter expressions
  link          Combine objects/resources into deterministic relocatable COFF
  capabilities  Print the implemented compatibility surface and remaining gaps
  library       Inspect definitions and references in a COFF archive or ZIP object collection
  suite         Inspect a local fixture suite; --execute also checks output in isolated workers
  docs          Generate Markdown CLI reference and roff manuals from this command model
  completions   Generate command and option name completion from this command model
  module        Describe or document a versioned module manifest
  help          Print this message or the help of the given subcommand(s)

Options:
  -h, --help
          Print help

  -V, --version
          Print version

```

## bof2exe init

```text
Create an editable command-line schema for a BOF, optionally using CNA metadata

Usage: bof2exe init [OPTIONS] <INPUT>

Arguments:
  <INPUT>
          Tool schema (.toml), or a local BOF for direct conversion

Options:
      --format <FORMAT>
          Raw values follow this bof_pack format: b, i, s, z, Z

      --cna <CNA>
          Infer wire types from a CNA command without executing the script

      --command <COMMAND>
          Alias/subroutine containing the selected bof_pack call

      --variant <VARIANT>
          One-based bof_pack call index for commands with multiple pack calls

      --name <NAME>
          Generated command name; defaults to the BOF filename or schema name

      --description <DESCRIPTION>
          Description shown in the generated command's help

  -e, --entry <ENTRY>
          

  -o, --output <OUTPUT>
          New schema path; defaults to the object name with .tool.toml

  -h, --help
          Print help

```

## bof2exe run

```text
Run an object in a separate worker process (Windows x64)

Usage: bof2exe run [OPTIONS] [OBJECT] [-- <ARGUMENTS>...]

Arguments:
  [OBJECT]
          Local standard COFF object

  [ARGUMENTS]...
          Replace manifest defaults with typed arguments after --

Options:
      --manifest <MANIFEST>
          TOML manifest; relative object paths resolve beside this file

  -e, --entry <ENTRY>
          Override the manifest entrypoint (otherwise defaults to go)

      --timeout <TIMEOUT>
          Deadline in seconds; terminate the worker when it expires
          
          [default: 30]

      --json
          Return callback kinds and raw byte arrays as JSON

      --format <FORMAT>
          Raw values follow this bof_pack format: b, i, s, z, Z

      --cna <CNA>
          Infer wire types from a CNA command without executing the script

      --command <COMMAND>
          Alias/subroutine containing the selected bof_pack call

      --variant <VARIANT>
          One-based bof_pack call index for commands with multiple pack calls

  -h, --help
          Print help

```

## bof2exe link

```text
Combine objects/resources into deterministic relocatable COFF

Usage: bof2exe link [OPTIONS] [OBJECTS]...

Arguments:
  [OBJECTS]...
          

Options:
      --spec <SPEC>
          Versioned TOML composition spec; paths resolve beside the spec

  -L, --library <LIBRARIES>
          Search a .lib/.a archive or ZIP collection for required COFF members

      --whole-archive
          Include every supplied library member, instead of resolving on demand

  -o, --output <OUTPUT>
          New COFF output path (required unless --plan is set)

      --plan
          Inspect the link result without writing it

  -e, --entry <ENTRY>
          

      --json
          

  -h, --help
          Print help

```
