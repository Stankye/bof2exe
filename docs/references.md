# Related projects

These projects provide context for BOF runtimes, module composition, and testing. Their interfaces and compatibility claims are separate from this project's [support matrix](compatibility.md).

| Project | Area |
| --- | --- |
| [Coffee](https://github.com/hakaioffsec/coffee) | Rust BOF loader and command-line interface |
| [coffeeldr](https://github.com/joaoviictorti/coffeeldr) | Rust loader library |
| [TrustedSec COFFLoader](https://github.com/trustedsec/COFFLoader) | C COFF loader |
| [bof-launcher](https://github.com/The-Z-Labs/bof-launcher) | BOF runtime and language integration |
| [Tradecraft Garden](https://tradecraftgarden.org/tradecraft.html) | Module, library, and runner documentation |
| [Atomic BOFs](https://github.com/rasta-mouse/atomic-bofs) | BOF test units and harness |
| [TrustedSec situational-awareness BOFs](https://github.com/trustedsec/CS-Situational-Awareness-BOF) | External objects used by the opt-in validation tests |

Implementation provenance and dependency notices are recorded in [THIRD_PARTY.md](../THIRD_PARTY.md). Results for the pinned TrustedSec corpus are in the [validation report](trustedsec-validation.md).
